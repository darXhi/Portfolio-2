Application

  • This project was developed to help estimate rice crop yield based on agriculture factors such as land area, fertilizer usage, rainfall, and other cultivation parameters. The goal was to provide a simple prediction tool that can support farmers and stakeholders in making better farming decisions. I was responsible for preparing the dataset, performing data preprocessing, training and evaluating several machine learning models, and integrating the selected model into a Streamlit web application. Besides the prediction model, I also designed the interface to ensure the application is easy to understand and comfortable to use. During development, I learned how data quality affects prediction accuracy, how to compare different machine learning algorithms, and how to present technical results through a user-friendly interface. This project strengthened my understanding of the complete machine learning workflow, from data preparation to development.
